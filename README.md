# WaferFlow — Memory Fab Integration

기본 화면을 **DRAM·3D NAND·HBM 연계 경로 / 21개 장비군 / 48개 가상 챔버**의 팹 통합 공간으로 바꿨습니다. 장비 적합성·공유 자원 대기·LOT 이력·상류 편차·후속 계측 보류를 연결하고, 챔버 제외나 조건 변경의 전체 영향을 비교합니다. 공개 원리 기반의 미보정 참조 모형이며 SK하이닉스 실제 장비·공정 데이터가 아닙니다.

기존 **117개 CMOS 공정·18개 장비·누적 단면과 브라우저 실험 기록**은 `cmos-lab.html`에서 유지합니다. 이온 밀링 응답과 서버 검토 기록도 보존합니다. [새 팹 공간의 사용법·모델·기업 파일럿 범위](docs/MEMORY-FAB.md).

**모델 근거 검증**(`evidence.html`)에서는 HAR 식각 깊이·CVD 두께·CMP 단차의 계측 JSON을 입력하고, 과거 LOT으로 보정한 뒤 이후 LOT에서 오차를 확인합니다. 단위·중복·시각 검사, LOT 분리, 계획 고정, 잔차·범위 점검, 검증 자료 재사용 표시, SHA-256을 포함한 JSON/HTML 검토 패키지를 제공합니다. 실제 기업 자료는 포함하지 않습니다. [입력 형식과 검증 방법](docs/MODEL-EVIDENCE.md).

저장소에는 소스·실행 의존성 명세·라이선스·검사 코드와 합성 테스트 fixture만 포함합니다. DB·사용자 계측 파일·백업·가상환경·생성 결과는 제외합니다. 설치와 실행은 아래 절차를 따르세요.

## 실행

Python 3.12 이상에서 프로젝트 폴더의 [start-review.ps1](start-review.ps1)을 실행합니다.

```powershell
.\start-review.ps1
```

[http://127.0.0.1:8766/](http://127.0.0.1:8766/)에서 Fab 시뮬레이터를 바로 사용합니다. 서버 검토 공간은 [/workbench.html](http://127.0.0.1:8766/workbench.html)에서 첫 관리자 계정을 직접 설정합니다. 기존 포토 실험실은 [/photo-lab.html](http://127.0.0.1:8766/photo-lab.html)입니다. 이미 설치했으면 `.\.venv\Scripts\python.exe run_server.py`로 바로 실행할 수 있습니다.

프로젝트 전체를 정적 서버로 공개하지 마세요. 허용한 화면 파일만 제공하는 전용 서버를 사용합니다. DB는 기본 `.data/waferflow.sqlite3`에 보관합니다.

## 0.5 CMOS Fab — 별도 단면 실험실

별도 **[장비 운전실](http://127.0.0.1:8766/equipment.html)**을 추가했습니다. 이온 밀링 장비의 레시피 점검, 조건 기반 7단계 운전, 챔버 절개도, 센서 응답·설정값 그래프, 진공·냉각·빔 고장 시험, JSON 로그 재생을 제공합니다. 공개 채널 명세를 참고한 **자체 생성 예제**이며 삼성·SK하이닉스 실측 데이터가 아닙니다. 기존 CMOS 기록은 유지합니다. [사용법과 데이터 형식](docs/EQUIPMENT-CONSOLE.md).

장비 운전실의 **레시피·실험 검토**에서 서버 보관, 불변 버전, 기준 운전 비교, 동료 검토 요청·완료·반려와 HTML 보고서를 사용합니다. 기존 계정·프로젝트를 공유하고 장비 기록은 별도 테이블에 저장합니다. 장비 투입 승인이 아닌 사내 검토 파일럿입니다. [업무 흐름·권한·운영 범위](docs/EQUIPMENT-REVIEW.md).

- 웰 → STI → 게이트 → LDD·스페이서·S/D·실리사이드 → 콘택트 → M1 → VIA/M2 → 패시베이션·검사
- 117개 세부 공정과 18개 장비 유형. 공정 선택 시 해당 장비, 마스크, 재료, 레시피 표시
- 웨이퍼 이송, 스핀, 노광, 플라즈마, 주입, 가열, CMP의 관찰용 3D 동작
- 장비 클릭 또는 ‘장비 설명’으로 18종 장비의 역할·작동 순서·부품·조건별 영향 확인. Enter/Space도 지원
- 설명을 여는 동안 실행을 일시정지하고, 부품 설명에서 해당 3D 위치로 이동
- 이송의 들어올림·가감속·안착, 로봇 복귀, 노즐·커버 움직임, 스핀과 공정 효과의 점진적 시작·종료
- 4.8 µm 대표 단면을 160개 열로 계산. 산화의 Si 소비, PR 잠상·현상, 마스크 차폐, 식각 선택비, 주입·활성화, CMP 상태 전달
- 완료 공정의 수치를 바로 수정하고 새 분기에서 실행. 원본 실행 기록은 보존하며 초안은 별도 저장
- 일시정지 중 조건 수정과 재시작, 단일·연속 실행, 0.5–8배 애니메이션, 설정 처리 시간 별도 누적
- 스테이지 이동→정지→노광/계측/프로브 접촉, CMP 패드·캐리어·웨이퍼 회전, 막과 잠상의 점진적 색 변화
- 실행 기록을 바꾸지 않는 조건 미리 계산, 동일 입력 웨이퍼의 5조건 스윕과 조건 불러오기·JSON 저장
- 미래 공정 미리 보기와 선행 공정 계산. 잔사 경고 및 진공 인터록에서 연속 실행 중지
- 완료 이력의 전·후 단면, 위치별 막 두께, 계측 지점과 표본 표준편차
- 동일 공정 시점 선택, A/B 표면 높이 그래프, 실제 실행 레시피 차이와 비교 근거 JSON. 최대 25개 웨이퍼
- 실험 이름·가설·관찰 메모, 독립 HTML 리포트, 브라우저 로컬 저장, JSON 재계산 복원과 이력 CSV
- 미완료 공정 취소, 앞 공정 계산 중단·이어가기와 5공정 단위 저장. 탭 숨김·3D 연결 손실 시 일시정지
- 입력란별 오류 안내, 결과 탭의 방향키/Home/End 탐색, 다음 대기 공정 찾기. Fab 기록은 서버 검토 DB와 별개

### 빠른 사용

1. 왼쪽의 **게이트 형성 → 폴리 게이트 패턴 식각**을 선택합니다.
2. **앞선 공정 계산**을 누르면 입고부터 해당 식각 직전까지 웨이퍼가 계산됩니다.
3. **선택 공정 실행**으로 장비 처리와 아래 단면에서 게이트 형성을 관찰합니다.
4. 완료된 공정의 식각 시간·파워를 바로 바꾸고 **조건 미리 계산** 또는 **조건 스윕**으로 영향을 확인합니다. 이 단계에서는 실행 기록이 바뀌지 않습니다.
5. **이 조건으로 새 실험**을 누르면 원본을 보존한 분기 웨이퍼에서 실행합니다. **분기 비교**에서 원본 웨이퍼와 공정 시점을 골라 형상·조건 차이를 확인합니다.
6. 왼쪽 **실험 이름 · 메모**에 가설과 관찰을 적고 결과 영역의 **실험 리포트**를 내려받습니다. 복원 가능한 원본은 상단 **JSON 내보내기**로 함께 보관합니다.
7. 실행 중 수정을 원하면 **일시 정지** 후 값을 바꾸고 **변경 조건으로 다시 시작**을 누릅니다. 전체 흐름은 새 웨이퍼에서 **연속 실행**을 켭니다. 8배 재생의 설명용 시간은 약 1분 30초이며 기기 성능에 따라 늘어날 수 있습니다.

모델 수식·공정 가정·자료 출처·저장 범위는 [Fab 모델 문서](docs/FAB-MODEL.md)에 있습니다.

## 0.4 엔지니어링 검토 기능 (기존 포토 12변수 모델)

- Flask / Waitress + SQLite로 계정·조건·실험·검토 기록 저장
- 관리자 / 엔지니어 / 검토자 역할, 작성자의 자기 승인 금지
- 내용이 고정된 레시피 버전과 이전 버전 대비 조건 차이
- 시나리오·시드·모델 해시를 포함하는 서버 계산 결과
- Lot / wafer / site 식별자와 출처를 포함한 CSV 계측 데이터
- 계측·합성 모델·합성 예시 구분, CD 표본 통계·규격선 차트
- 검토 요청 이후 조건과 근거 고정, 승인·반려 의견 보존
- 동시 수정 충돌 검출, 세션 회수, 변경 이력, 원본 결과 내보내기
- 일관된 DB 백업과 복원 검증, 3D 장비실과 새 변경안 작성 연결

운영 범위·계정·CSV·백업·검증 방법은 [운영 문서](docs/OPERATIONS.md), API는 [API 문서](docs/API.md)에 있습니다.

## 0.3 화면 개선

- 반사 환경과 장비별 조명, 모서리 마감, 금속·세라믹·석영 재질
- 노광기 광학 헤드·마스크 홀더, 식각기 플랜지·배기 배관, 코터 배액 컵·공급 노즐 등 기계 구조 보강
- 각 장비의 부품 3개를 화면에서 선택하고 역할 설명 확인
- 타임라인 드래그로 되감기, 투입·안착·가공·확인 구간 바로 이동
- 노즐 회전과 베이크 커버 개폐, PR 확산·잠상·현상·식각·제거의 순차적 표면 변화
- 장비별 척 높이에 맞춘 웨이퍼 안착, 해당 장비를 중심으로 보는 탑뷰
- 읽기 쉬운 버튼·설명 크기와 모바일 레이아웃

## 기존 포토 실험실의 구현 내용

- 공정별 전용 장비 화면: 산화로, 스핀 코터, 소프트베이크 핫플레이트, 마스크 노광기, PEB 핫플레이트, 현상기, 플라즈마 식각기, PR 스트리퍼
- 공정 버튼을 누르면 해당 장비만 표시하고 시점을 이동합니다. ‘이 장비 가동’으로 단독 가공 후 ‘다음 공정’으로 넘어갑니다.
- 전체 장비실: FOUP/카세트, 이송 로봇, 8개 모듈 사이를 이동하는 단일 웨이퍼
- 회전·확대·탑뷰·내부 투시·자동 추적, 가동/일시정지/초기화, 0.5–4배 재생
- 회전 척, PR 도포 확산, 현상액 공급, 핫플레이트, 마스크·UV 빔, 플라즈마와 패턴 변화
- 포토 공정을 중심으로 산화 → PR 도포 → 소프트베이크 → 정렬·노광 → PEB → 현상 → 식각 → PR 제거의 8개 장면
- 양성 PR의 노광 직후 잠상과 현상 후 제거를 구분한 SVG 시각화
- 공정 장면, 적층 단면, 다이별 불량 맵 / 기준 레시피와 비교
- 온도·시간·RPM·노광량·초점·RF 파워·압력 등 12개 입력
- 같은 레시피와 시드에서 같은 결과를 만드는 결정적 합성 모델
- 3개 불량 미션, 가설 기록, 로컬 레시피 저장 및 실험 복원
- 9조건 단일 변수 스윕, 30시드 반복 통계, 식각 깊이 히스토그램
- 독립 HTML 리포트, CSV 실험 기록, JSON 통계 내보내기
- 모델 안내와 공식 출처를 모은 리서치 화면

**화면의 8단계는 반도체 ‘8대 공정 전체’를 뜻하지 않습니다.** 포토리소그래피와 인접 공정을 나눈 교육용 흐름입니다. 실제 장비 UI, TCAD, 제조 레시피, 실제 팹 통계는 아닙니다. PEB 필요성과 목적은 감광액·레시피에 따라 달라집니다.

## 기존 포토 실험실 데모

1. 상단 공정 선택에서 ‘감광액 도포’를 누릅니다. 스핀 코터만 표시되는 전용 장비 화면에서 ‘이 장비 가동’을 누릅니다.
2. ‘다음 공정’으로 핫플레이트와 노광기, 현상기를 차례로 확인합니다. 아래 ‘웨이퍼 단면’에서는 잠상과 실제 제거의 차이를 관찰합니다.
3. 노광량을 100 mJ/cm²로 바꾸고, 현상 시간을 60 s로 바꿉니다.
4. 가설을 적고 ‘전체 공정 실행’을 누릅니다. 초기 미션의 합성 수율은 39.0% → 97.5%로 변합니다.
5. ‘기준 비교’, ‘불량 맵’, ‘실험 · 통계 분석’을 확인합니다.
6. 레시피를 저장하고 리포트를 내보내 면접용 문제 해결 과정을 설명합니다.

이 수율 차이는 **이 프로젝트의 교육용 모델에서만** 성립합니다. 실제 공정 개선 성과로 사용하면 안 됩니다.

## 검증

장비 사전 검토 연결 업데이트에서는 엔진·UI·서버 154개와 실제 HTTP 업무 흐름 4개, 총 **158개**를 통과했습니다. 상세 범위는 [장비 검토 안내](docs/EQUIPMENT-REVIEW.md)를 참고하세요.

Node.js 20 이상이 있는 환경에서 다음 명령으로 모델 및 DOM 테스트를 실행합니다.

```powershell
node --input-type=module -e "import('./tests/fab-tests.mjs').then(async m => console.log(await m.runFabTests(process.cwd())))"
node --input-type=module -e "import('./tests/run-tests.mjs').then(async m => console.log(await m.runTests(process.cwd())))"
```

테스트 결과는 `tests/fab-results.json`과 `tests/results.json`에 기록됩니다. 서버 검증은 `.\.venv\Scripts\python.exe -m unittest tests.test_review -v`로 실행합니다. 테스트용 DOM은 `linkedom@0.18.12`의 독립 배포 파일을 사용합니다. 라이선스는 `tests/LINKEDOM-LICENSE`이며 앱 런타임에는 사용하지 않습니다.

앞선 CMOS 화면 업데이트에서 Fab 모델·UI·3D 검증 **56개**, 기존 포토 모델·3D 검증 **39개**, 서버 검증 **21개**, 총 **116개**를 다시 통과했습니다. 기존 실제 HTTP 검토 UI 검증 11개는 이전 검증 결과이며 이번 화면 변경에서 재실행하지 않았습니다.

Fab 검증은 완료 조건 편집과 원본 보존, 일시정지 후 변경·재시작, 미리 계산·스윕의 비커밋 동작, 비교 시점과 내보내기 재현성, 실험 메모·독립 리포트, 중단·재개, 키보드 탐색, 장비 움직임의 연속성, CMP 회전, 3D 연결 손실 이벤트와 자원 해제를 포함합니다. Three.js의 실제 장면 그래프를 만들고 테스트에서는 WebGL renderer만 대체합니다. **CSS/GPU 렌더링과 실제 브라우저 시각 검증은 별도입니다.** 현재 작업 환경의 브라우저 연결 부재 및 화면 캡처 실행 차단으로 스크린샷 검증은 완료하지 못했습니다. 실제 팹 데이터에 대한 모델 보정·정확도 검증과 장기 운용 검증도 남아 있습니다.

## 기존 포토 실험실 및 서버 검토 기능의 한계

- 장비실은 Three.js 기반으로 회전·확대 가능한 3D 모델이며, 세부 공정 분석은 SVG 개념도입니다. 특정 제조사의 CAD, 실장비 촬영, 실제 제어 UI를 복제한 것은 아닙니다.
- 3D에는 WebGL을 지원하는 브라우저가 필요합니다. 실패 시 안내를 표시하고 기존 단면·통계 기능은 유지합니다.
- 장비실의 단독 가동은 11초, 전체 흐름은 88초로 설명용 재생입니다. 수치 실험 기록은 별도로 ‘전체 공정 실행’을 눌러 남깁니다.
- 노광의 회절·간섭·광화학 반응·PEB 확산·현상 표면 진화는 수치적으로 풀지 않습니다.
- 레이어별 높이는 가독성을 위해 과장되며 실제 치수 비율이 아닙니다.
- 단일 조직 서버 저장·역할·동료 검토를 구현했습니다. 클라우드 SSO, 다중 조직 격리, 프로젝트별 권한, 인증된 평가·수료증, 실제 PDK 실행은 구현하지 않았습니다.
- 실험은 최근 200개, 레시피는 최근 50개를 이 브라우저에 보관합니다. 장기 보관에는 내보내기를 사용하세요.
