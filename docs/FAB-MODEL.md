# CMOS Fab 계산 모델 0.5

## 목적과 기준 흐름

장비 유형, 공정 조건, 재료 단면의 관계를 실행·비교하는 엔지니어링 프로토타입이다. 일반적인 평면형 gate-first CMOS와 Al 2층 배선을 예시로 선택했다. 특정 제조사의 레시피나 SKY130 공정을 복제한 모델이 아니다. 공개된 공정 원리를 근거로 순서와 동작을 구성했으며, 모든 정량 계수는 독립적인 설명용 값이다.

| 구간 | 주요 작업 |
|---|---|
| 웰 | 세정, N/P 웰 마스킹·주입, 활성화 |
| STI | 패드 산화막·질화막, ACTIVE 패터닝, Si 트렌치, 라이너, 산화막 충전, CMP·하드마스크 제거 |
| 게이트 | 산화막, 폴리 증착, POLY 패터닝·식각, CD 확인 |
| 접합 | N/P LDD, 질화막 스페이서, N/P S/D, RTA, NiSi |
| 콘택트 | ILD, CMP, 홀 개구, TiN 장벽막, W 충전·CMP |
| M1 | Al 증착, 패터닝·식각, 세정 |
| VIA / M2 | IMD·CMP, 비아, TiN/W·CMP, Al M2 패터닝 |
| 마무리 | SiN 보호막, PAD OPEN, 구조 계측, 프로브 접촉 동작 |

도포·베이크·노광·현상은 각 마스크마다 반복한다. 117개 작업이 순차적으로 실행되며 공정 순서는 `fab-engine.js`의 `route`가 유일한 기준이다. 18개 장비 레시피를 사용한다. 비화학증폭 양성 PR을 가정해 PEB는 이 예제에서 생략한다. 실제 팹에는 더 많은 세정·검사·재작업과 다른 물질·순서가 존재한다.

## 자료 출처와 사용 범위

- [ASML, Lithography principles](https://www.asml.com/en/technology/lithography-principles): 마스크 상을 웨이퍼에 전사하는 투영 리소그래피 원리. 광학 구조와 단계의 역할을 참고했다.
- [Lam Research, Our processes](https://www.lamresearch.com/products/our-processes/): CVD·ALD, 절연막·금속 형성, 식각·세정의 공정 역할을 참고했다.
- [Applied Materials, Semiconductor products](https://www.appliedmaterials.com/us/en/semiconductor/products.html): 이온주입·열처리·CMP 등 장비 범주를 참고했다.
- [SkyWater PDK, Layers](https://skywater-pdk.readthedocs.io/en/main/rules/layers.html): 공개 공정 층과 마스크 역할을 참고했다. 본 모델은 해당 PDK의 제조 조건이나 설계 규칙을 실행하지 않는다.

이 출처들이 아래의 예제 계수·조건·정량 정확성을 보증하는 것은 아니다. 비공개 IP·장비 CAD·실제 팹 통계는 수집하거나 포함하지 않았다.

## 상태와 계산

대표 단면의 가로 폭은 4,800 nm이며 160개 열, 즉 30 nm 격자로 나눈다. 각 열에는 아래에서 위로 `{material, nm}` 스택을 보관한다. 최초 Si 표시 두께는 600 nm이다. 실제 웨이퍼 전체 두께나 전체 다이를 수치 해석하는 모델이 아니다. 세로 높이는 부동소수점 nm로 계산한다. 3D 웨이퍼 표면의 다이 반복은 설명용 표현이다.

`execute`는 현재 웨이퍼를 변경하지 않고 복사한 후 한 작업을 계산한다. 종료 시 조건·경고·결과·모델 버전·시각을 기록한다. `replay`는 최초 웨이퍼부터 기록된 순서와 조건을 다시 실행한다. 따라서 과거 보기와 분기는 동일한 결과를 재현한다. 다른 모델 버전의 기록은 거절한다.

| 공정 | 사용한 축약 모델 | 주요 생략 |
|---|---|---|
| 산화 | `x² + A·x` 형태 성장. A=120 nm, B=240·exp((T−1000)/95) nm²/min. 생성 산화막의 0.44배 Si 소비 | 응력·결정방향·실제 가스 분위기 |
| CVD/PVD | 작업별 기준 속도 × 시간, 온도·유량 또는 타깃 파워 보정 | 화학 반응계·입체 수송·공극 |
| ALD | 사이클 × 예제 GPC 0.1 nm. 200–300°C 성장 창 밖은 예제 감쇠 | 실제 전구체별 포화·퍼지 동역학 |
| PR | 기준 600 nm × sqrt(3000/RPM), 처리 시간 보정 | 점도·용매 유동·에지비드 |
| 노광 | 이진 마스크를 가우시안 블러 처리. 초점 오프셋에 따라 블러 폭 증가. 도즈·베이크 계수 반영 | 파동광학·간섭·레지스트 광화학 |
| 현상 | 노광 도즈의 6차 포화 응답으로 위치별 PR 제거 속도 계산 | 현상액 수송·측벽 진화 |
| 식각 | 파워^0.7 · 압력^−0.12 · 시간. PR 선택비 8, 표적 외 물질 선택비 150 | 플라즈마 해석·등방 식각·실제 선택비 |
| 주입 | 종별 에너지→Rp 계수, 틸트 cos 보정, Gaussian 깊이 분포. 상부 막에 따른 지수 차폐 | 결정 채널링·산란·3D 손상 |
| 열처리 | 온도에 따른 활성화 속도와 Gaussian 폭 확산 | 고농도 상호작용·완전한 열 이력 |
| 실리사이드 | Ni/Si 반응량과 유지 시간, Si 소비·NiSi 생성. 미반응 Ni는 상층에 보존 | 상전이·결정구조·응력 |
| CMP | 제거량 ∝ 압력 × 회전 속도 × 시간. 설정 평면 또는 SiN 정지막까지 제거 | 패턴 밀도·디싱·실제 선택비 |
| 계측 | 현재 단면에서 균등 간격으로 지점 추출, 높이·최상층 두께 | 실제 센서 노이즈·웨이퍼 전면 분포 |

측정 화면의 표본 표준편차는 선택한 N개 표면 높이에 대해 `sqrt(sum((x−mean)²)/(N−1))`로 계산한다. 공정 능력·수율·신뢰구간을 추정하지 않는다. 게이트 폭은 남은 Poly 구간의 평균 폭이며 최소 30 nm 격자 한계를 가진다. 활성 비율은 주입 이력별 활성화 계수의 산술 평균이며 전기 성능을 의미하지 않는다. 농도 표시는 활성 도펀트의 순농도에 p형 배경 1e15 cm⁻³를 더한 값이다.

온도·시간 등 필드 범위는 이 모델의 입력 범위이며, 실제 장비 사용 가능 조건이나 제조 처방이 아니다. 프로브 단계는 구조 확인과 접촉 장면만 제공하며 트랜지스터 I–V, 누설, 저항, 연결성 검증 또는 전기 수율을 계산하지 않는다.

## 이상 조건과 실행 제어

- 노광 출력 저하: 노광 작업에서 유효 도즈를 설정치의 55%로 계산한다. 현상 잔사가 주입 차폐나 후속 식각에 전달된다.
- 불균일 증가: 막 성장·코팅·식각에 적용되는 위치 편차 계수를 늘린다. 이는 실제 wafer-map 통계가 아니다.
- 진공 도달 실패: 진공 장비에서 실행 전 인터록을 걸어 재료 상태를 유지한다. 발생 기록은 별도 이력으로 보관한다.
- 이전 PR이 남아 있으면 다음 도포를 보류한다. 미제거 PR이 발생한 공정에서 분기해 제거 조건을 수정할 수 있다.
- 자동 실행은 결과 경고·인터록·공정 완료에서 멈춘다. 완료된 공정의 입력란도 편집할 수 있지만 변경값은 초안으로 저장된다. ‘이 조건으로 새 실험’은 선택 공정 직전 상태를 새 웨이퍼로 분기해 실행하며 원본 완료 기록은 바꾸지 않는다. ‘원본 실행 조건 불러오기’로 초안을 되돌릴 수 있다.
- 실행 중에는 입력을 잠그고, 일시정지하면 편집할 수 있다. 조건을 바꾸지 않았으면 계속 실행하고, 바꾸었으면 마지막 완료 상태에서 현재 공정을 처음부터 다시 계산한다. 취소는 진행 중인 미완료 계산만 버리고 완료 기록과 유효한 초안을 유지한다.
- 미래 공정 보기만으로 웨이퍼를 가공하지 않는다. ‘앞선 공정 계산’은 실제 엔진을 순서대로 호출한다. 5개 공정마다 저장하고 UI에 제어를 돌려주며 사용자가 중단할 수 있다. 중간 경고 발생 시 해당 지점에 멈춘다. 다시 계산하면 완료한 공정 다음부터 이어간다.

화면 재생은 작업당 6초를 0.5–8배속으로 압축한다. 레시피 처리 시간은 별도 누적하며 이송 시간·대기열·장비 점유율은 계산하지 않는다. 탭을 숨기거나 3D 연결이 끊기면 진행 중인 애니메이션 실행을 일시정지하며 사용자가 계속 실행해야 재개한다. 실행 중 새로고침하면 마지막으로 저장된 완료 공정까지만 복원한다. 단일 실행은 공정 종료마다, 앞 공정 일괄 계산은 5공정마다 및 종료·중단 시 저장한다.

## 미리 계산·조건 스윕·분기 비교

‘조건 미리 계산’은 선택 공정 직전의 웨이퍼와 현재 입력 조건으로 `process`를 한 번 호출한다. 단면과 구조 지표를 볼 수 있지만 커서·누적 처리 시간·실행 기록을 갱신하지 않는다. 입력을 수정하거나 다른 공정을 선택하면 미리 계산 결과를 지운다. 선행 공정이 없는 미래 공정에서는 사용할 수 없다.

‘조건 스윕’은 한 변수의 시작값·끝값 사이에서 최대 5개 조건을 계산한다. 변수의 지원 입력 간격에 맞는 값만 선택하고 중복은 제외하며, 서로 다른 두 값도 만들 수 없는 구간은 거절한다. 모든 조건에 같은 입력 웨이퍼를 사용한다. 다른 변수와 이상 조건은 계산을 시작할 때의 입력값으로 고정한다. 그래프의 응답 지표는 공정에 따라 막 두께·단차·유효 노광량·투과 주입량·활성 비율·베이크 응답 계수·잔여 오염 지표 중 하나이다.

스윕은 일시적인 계산이며 웨이퍼 완료 기록에 추가되지 않는다. ‘불러오기’는 해당 행의 전체 레시피와 이상 조건을 초안에 적용한다. 스윕 JSON에는 모델 버전·입력 공정 이력·고정 조건·각 조건과 응답·경고를 담는다. 파일 스키마는 `waferflow-fab-sweep-v1`이며 별도의 분석용 출력이다. 이 파일을 전체 실험 복원용 JSON으로 가져올 수는 없다.

‘분기 비교’는 두 웨이퍼가 모두 완료한 공정 중 비교 시점을 선택해 재계산한다. 기본은 최신 공통 완료 시점이다. 같은 160개 위치의 표면 높이·구조 지표와 그 시점까지 실제 실행한 레시피 차이를 보여준다. 아직 실행하지 않은 초안은 비교에서 제외한다. 비교 JSON(`waferflow-fab-comparison-v1`)은 양쪽의 선택 시점까지의 완료 기록·메모·구조 요약·위치별 표면 높이·조건 차이를 포함한다. 스윕과 비교 모두 실측 분포·공정 능력·신뢰구간을 의미하지 않는다.

## 저장·복원과 기존 검토 공간

Fab 상태는 `waferflow-fab-v05`라는 브라우저 로컬 저장소 키에 저장한다. 최대 25개 웨이퍼를 지원하며 각 웨이퍼의 완료 이력·공정별 초안·이상 조건·분기 출처·실험 이름(60자)·메모(2,000자)를 보관한다. 메모는 모델 계산에 영향을 주지 않으며 분기 시 복사된다. 저장 실패는 상단에 표시한다. JSON을 내려받아 별도 보관할 수 있다.

JSON 복원은 12 MB 이하 파일만 받는다. 버전·순서·레시피 필수값·범위·이상 조건을 검증한 후 원본 레시피로 재계산한다. 가져온 결과 요약을 신뢰하지 않는다. 기존 웨이퍼를 덮어쓰지 않고, ID 충돌 시 새 이름으로 추가한다. JSON의 타임스탬프와 내용은 사용자가 수정할 수 있으므로 감사 증빙·승인 문서가 아니다.

‘실험 리포트’는 현재 웨이퍼 전체의 완료 기록·원본 실행 조건과 단위·UTC 실행 시각·경고·최종 구조·메모를 독립 HTML로 내보낸다. 과거 공정을 보고 있거나 미리 계산을 띄웠어도 리포트는 완료 이력의 최종 상태를 사용하며 미실행 값은 제외한다. 외부 스크립트·폰트·이미지 없이 열람할 수 있고 브라우저 인쇄를 위한 스타일을 포함한다. 출력 PDF의 실제 페이지 배치는 별도 확인이 필요하다. 복원에는 리포트가 아니라 전체 이력 JSON을 사용한다. 이력 CSV에는 실험 이름·메모도 포함되며 수식으로 해석될 수 있는 셀의 시작 문자를 이스케이프한다.

`workbench.html`의 서버 검토 공간은 기존 포토 12변수 모델을 사용한다. Fab의 117단계 레시피가 자동으로 해당 DB에 저장되거나 승인되는 것은 아니다. 검토 공간의 ‘3D 장비에서 확인’은 `photo-lab.html`에 해당 레시피를 불러온다.

## 검증 범위

`tests/fab-tests.mjs`는 기준 117단계 완주, 단위·재료 상태, 산화 Si 소비, 노광·현상 구분, 잔사의 후속 전파, 마스킹, CMP, 주입, 실리사이드 잔여물, 인터록, 재현성, 불러오기 검증, 실행·정지·분기·연속 실행·계측 UI를 검사한다. Three.js 실제 지오메트리와 변환을 사용하고 WebGL 렌더러만 테스트에서 대체한다.

실측 데이터와의 정확도 검증, 브라우저 CSS 배치, GPU 렌더링, 장시간 성능 검증은 아직 수행하지 않았다. 물리 정확도나 양산 적합성을 주장하는 테스트가 아니다.


## 장비 설명과 관찰 동작

3D 장비를 짧게 클릭하거나 상단의 ‘장비 설명’을 누르면 현재 장비의 역할·처리 전후·작동 순서·주요 부품·레시피 조건별 영향을 확인할 수 있다. 캔버스에 포커스를 두고 Enter 또는 Space로도 열 수 있다. 드래그 회전·빈 배경 클릭·취소된 터치는 설명창을 열지 않는다. WebGL을 사용할 수 없어도 설명 버튼은 동작한다.

진행 중 설명을 열면 공정을 일시정지하며, 닫은 뒤 ‘계속 실행’으로 재개한다. 설명창은 레시피나 완료 기록을 변경하지 않는다. ‘3D에서 이 부품 보기’는 설명창을 닫고 해당 부품으로 시점을 이동한다. 원리 참고 링크는 장비별 설명 하단에 제공한다.

이송은 들어올림 → 이동 → 안착으로 나누고 각 구간에 5차 보간 곡선을 사용한다. 공정 종료 후에는 커버를 연 뒤 이송 로봇이 접근하고, 웨이퍼를 로드 포트로 되돌린다. 노즐·커버·스핀·광원·플라즈마의 동작도 공정 구간과 연동한다. 이 애니메이션은 이해를 돕는 모형으로, 실제 장비의 로봇 궤적이나 작동 시간을 검증한 것이 아니다.

노광·계측 스테이지는 대표 4개 위치 사이를 이동한 후 정지하여 광원 또는 프로브 접촉을 표시한다. 위치 개수와 궤적은 설명용이며 실제 계측 표본 수나 스캐너의 스캔 궤적과 같지 않다. CMP의 패드·캐리어·웨이퍼는 회전하고 일시정지 시 함께 멈춘다. 스핀 속도는 입력 RPM의 경향을 반영하되 화면에서 관찰 가능한 속도로 압축한다. 얇은 막과 노광 잠상의 색은 점진적으로 섞어 표시하며 실제 광학 반사율 계산은 아니다.

같은 장비를 다시 선택하거나 입력을 복원할 때 장면과 카메라를 유지한다. 다른 장비로 바꿀 때 이전 장면의 고유 지오메트리·재질·텍스처를 해제한다. 뷰포트를 해제할 때 남은 장면 자원·입력 이벤트·ResizeObserver·애니메이션 루프도 정리한다. 3D 연결 손실/복원 처리는 이벤트를 모사해 검증했으며 실제 GPU 장애 복구 시험은 아니다.
