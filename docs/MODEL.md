# 모델 명세 · wf-edu-0.2.0

## 1. 목적과 데이터 출처

이 엔진은 포토 공정의 인과 관계를 학습하고 재현 가능한 실험을 기록하기 위한 **교육용 대체 모델**입니다. 공개 원리의 함수 형태와 자체 가정 계수를 조합했으며 실측 데이터로 보정하지 않았습니다. 모든 수율·불량·비용은 합성값입니다.

정렬·노광 장면은 365 nm 교육용 광원을 표시합니다. 노광 모델은 특정 광학계나 실제 PR 제품을 재현하지 않습니다. 양성 PR을 가정하고 PEB를 포함하는 예시 레시피를 사용합니다. 정렬 장면은 표시하지만 overlay 오차 변수는 아직 구현하지 않았습니다.

## 3. 박막과 패턴

산화막은 Deal–Grove의 선형·포물선 관계 형태를 차용합니다. 실리콘 소모·계면 이동은 구현하지 않습니다.

```text
A = 180 nm                       [자체 가정]
B = 700 exp((T − 1000) / 90)     [nm²/min, 자체 가정]
x_oxide = (sqrt(A² + 4 B t) − A) / 2
```

이 온도 의존식은 온도 구간의 경향을 표현하는 자체 함수입니다. 실제 활성화 에너지를 쓴 Arrhenius 모델이 아닙니다. 매우 얇은 막, 습식 산화, 결정면 차이 등에 검증되지 않았습니다. 함수 형태 참고: [MIT OCW 산화 모델 강의](https://ocw.mit.edu/courses/6-774-physics-of-microfabrication-front-end-processing-fall-2004/resources/mit6_774f04_lec06_mp4/).

```text
PR 두께 = 850 sqrt(3000 / RPM) nm
베이크 패널티 = |T_SB − 100|/80 + |t_SB − 60|/200 + |T_PEB − 110|/120
현상 지표 = (Dose/100)(t_dev/60) max(0.5, 1 − 0.3 × 베이크 패널티)
PR 잔사 = max(0, 1 − 현상 지표) × PR 두께 × 0.18
개구 CD = 500 + 1.4(Dose − 100) + 40 Focus² + 0.5(t_dev − 60) nm
```

위 계수는 모두 자체 가정입니다. CD는 이 예제의 개구 폭이며 공정 노드가 아닙니다. PR 재료별 감광 반응과 현상 속도는 계산하지 않습니다. 소프트베이크와 PEB에 대한 설명은 [MicroChemicals 응용 자료](https://www.microchemicals.com/DOWNLOADS/Application-Notes/)와 [BYU Cleanroom](https://www.cleanroom.byu.edu/SOP_05PR)을 참고했습니다.

## 4. 식각과 다이별 변동

```text
식각 속도 = 1.25 (RF/220)^0.72 (30/압력)^0.12 nm/s
식각 깊이 = 식각 속도 × 식각 시간
가장자리 스트레스 = max(0, RF − 240)/130
편차 지표 u = 1.4 + 0.11|압력 − 30| + 0.0015|RPM − 3000|
다이 식각 깊이 = 깊이 × [1 + r³(u/100 + 0.3 × 가장자리 스트레스) + (noise−0.5) × 0.04]
다이 산화막 = 산화막 × [1 + (r²−0.5)u/100]
다이 잔류 = max(0, 다이 산화막 − 다이 식각 깊이) + PR 잔사
```

`r`은 중심에서의 정규화 거리입니다. 위 관계는 장비별 보편 법칙이 아닙니다. 플라즈마 전자 에너지 분포, 유동, 셰스, 선택비, PR 소모 및 잔사에 의한 국부 식각 차폐는 직접 해석하지 않습니다. 잔류 산화막과 PR 잔사를 단순 합산하므로 실제 단면을 예측할 수 없습니다.

27×27 격자에서 원형 영역과 노치를 적용해 **528개 다이**를 생성합니다. 300 mm 표기는 장면의 가정이며 실제 다이 면적을 통해 계산한 칩 개수가 아닙니다.

좌표·시드의 정수 해시를 균등 난수처럼 사용합니다. 반복 간 독립성이나 난수 품질을 통계적으로 인증한 생성기는 아닙니다. 동일 레시피 비교에는 같은 좌표 난수를 사용해 시드 효과를 고정합니다.

불량 확률은 과식각·잔류막·패턴 편차·배경 결함의 자체 위험 함수로 구성됩니다.

```text
P_fail = 1 − ∏(1 − 각 원인의 위험값)
다이 불량 = noise(seed, position) < P_fail
수율 = 100 × 정상 다이 수 / 전체 다이 수
```

각 불량 다이에 가장 큰 위험값의 원인 이름을 붙입니다. 이것은 합성 데이터 생성 과정의 분류이며 실제 root-cause 진단기나 AI 모델이 아닙니다. 자세한 계수와 상한은 `engine.js`의 `risks` 배열에 공개했습니다.

## 5. 비용과 시간

```text
가상 비용($) = 58 + 0.6 t_ox + 0.016 T_ox + 0.12 t_etch
                + 0.025 RF + 0.055 Dose + 0.05 t_dev
모듈 시간(min) = t_ox + t_etch/60 + t_dev/60 + t_softbake/60 + 6
```

실제 견적·장비 원가·전체 팹 cycle time이 아닙니다. 모든 변수의 비용을 모델링하지 않으며, 베이크 등의 비용은 고정비에 단순 포함합니다. 6분 고정 시간에는 PEB 1분과 기타 이송·처리 5분을 가정합니다.

## 6. 통계

- **히스토그램:** 528개 다이의 식각 깊이를 최솟값–최댓값의 동일 폭 8개 구간으로 집계합니다.
- **다이 깊이 표준편차:** 생성된 웨이퍼 전체 다이를 모집단으로 보고 분모 N을 사용합니다.
- **9조건 스윕:** 다른 입력과 시드를 고정한 one-factor-at-a-time 분석입니다. 변수 간 상호작용을 추정하는 완전 요인 DOE가 아닙니다.
- **30회 반복:** 레시피는 고정하고 미션 시드에 17씩 더해 합성 웨이퍼를 만듭니다. 공정 파라미터의 제조 변동 분포를 샘플링하지 않습니다.
- **표본 표준편차:** 수율 30개에 대해 분모 n−1을 사용합니다. 단위는 %p입니다.
- **평균의 정규 근사 95% 구간:** `mean ± 1.96 × s / sqrt(n)`, 0–100으로 제한합니다. 작은 표본의 정확한 t 구간, 부트스트랩 구간 또는 모델 불확실도 구간이 아닙니다.

이 통계는 `tests/results.json`의 테스트로 합계와 재현성을 검증합니다. 실측 데이터에 대한 정확도 검증은 수행하지 않았습니다.

## 7. 장면과 실행 상태

공정 분석 SVG는 재료와 단계 관계를 보여주는 비축척 개념도입니다. SVG 공정 재생은 단계당 2.6초이며 실제 공정 시간과 무관합니다. 일부 장면의 진행률 변화는 설명용 표현입니다.

3D 장비실은 별도 `machine.js`에서 원본 절차적 지오메트리로 구성합니다. 기본은 선택된 장비만 보여주는 전용 화면이며 단독 가공 후 정지합니다. 전체 장비실로 전환하면 단일 웨이퍼가 FOUP → 로봇 → 8개 모듈을 이동합니다. 모듈당 11초를 이송 30%, 가공 61%, 확인 9%로 나눠 재생하며 실제 장비 cycle time이 아닙니다. 장비 간 실제 팹 레이아웃, 충돌 검증, 로봇 동역학, 액체 유동, 온도장·전자기장을 해석하지 않습니다. 전용 장비 화면의 웨이퍼 투입은 장비 앞쪽에서 시작합니다.

소프트베이크와 PEB는 실제로도 열처리 장비 범주이므로 둘 다 핫플레이트 형태입니다. 여기서는 각각 별도 모듈로 표시합니다. 광원·마스크·웨이퍼의 관계는 일반화한 마스크 노광기 모델이며 특정 스캐너·스테퍼의 광학계를 재현하지 않습니다.

- 장면·단면·불량 맵·규칙 기반 설명: 현재 입력의 **미리보기**
- 하단 KPI·실험 노트·HTML 리포트: 마지막 **실행 결과**
- 통계 JSON: 분석 실행 시점의 레시피 스냅샷
- CSV: 실제 실행 버튼을 눌러 기록한 실험

향후 실측 박막/노광/식각 데이터로 계수를 보정하고, 학습·검증 데이터를 분리한 뒤 오차 및 적용 범위를 보고해야 실제 분석 도구로 확장할 수 있습니다.
