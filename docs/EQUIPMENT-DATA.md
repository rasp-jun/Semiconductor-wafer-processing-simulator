# 실장비 데이터 확보 범위와 공개 자료 후보

확인일: 2026-09-18. 목표는 웨이퍼 투입 전 레시피 수치·장비 동작을 검토하는 시뮬레이터다. 이번 조사는 공개 1차 자료의 출처와 적용 범위를 확인한 것이다. 삼성전자·SK하이닉스 생산라인의 원본 레시피, 센서 시계열, PLC 코드, 장비별 인터록 설정은 확보하지 않았다. 아래 연구 데이터를 두 회사의 생산 데이터로 표시하지 않는다.

## 회사·제조사가 공개한 자료

장비의 도입 발표는 특정 제품의 모든 층에서 그 장비를 사용한다는 증거가 아니다. 제조사 제품 사양의 처리량도 현장 레시피의 실제 처리 시간을 뜻하지 않는다. 소개 자료의 열람과 장비 데이터·CAD의 재배포는 별개다. 이번에는 출처 링크와 요약만 기록했다.

## 공개 연구 데이터 후보

### PHM 2018: Ion Mill Etching

- [공식 설명과 열 정의](https://phmsociety.org/conference/annual-conference-of-the-phm-society/annual-conference-of-the-prognostics-and-health-management-society-2018-b/phm-data-challenge-6/)
- [공식 페이지에 연결된 아카이브](https://drive.google.com/file/d/15Jx9Scq9FqpIGn8jbAQB_lcHSXvIoPzb/view)
- 공식 설명은 여러 실제 이온 밀링 식각장비의 시계열이라고 명시한다. 시각·장비·레시피·단계 식별자, 챔버 압력, 빔 전압·전류, 냉각 계통, 회전·틸트·셔터 등을 포함하는 24개 열 명세가 있다.
- 익명화로 공학 단위가 공개되지 않았다. 레시피는 범주 식별자이므로 실제 단계별 설정값을 복원할 수 없다. 숫자에 임의로 Pa, Torr, W, sccm 등을 붙이지 않는다.
- 고장 라벨의 시각은 작업자가 정비를 위해 장비를 정지한 시점이다. 이를 고장 발생의 정확한 시작 시각으로 취급하지 않는다.
- 적합한 용도는 과거 로그 재생·상태 변화 관찰·이상 감지 기능의 검토다. 변경한 레시피의 동작 예측이나 반응성 플라즈마 식각의 물리 모델 보정에는 별도 근거가 필요하다.
- 제조사·장비 모델·삼성/SK하이닉스 팹 출처는 확인한 설명에 명시되어 있지 않다.
- 접근 상태: 아카이브 파일 제목은 확인했지만 원본 파일은 다운로드·검사하지 않았다. 이번 열람에서는 데이터의 상업 이용·재배포 조건도 확인하지 못했다. 앱에 원본 데이터를 포함하기 전 배포 조건과 접근 가능 여부를 확인해야 한다.

### UCI SECOM

- [공식 데이터 설명·CC BY 4.0 안내](https://archive.ics.uci.edu/dataset/179/secom)
- [공식 ZIP](https://archive.ics.uci.edu/static/public/179/secom.zip)
- [원본 측정 파일](https://archive.ics.uci.edu/ml/machine-learning-databases/secom/secom.data), [라벨 파일](https://archive.ics.uci.edu/ml/machine-learning-databases/secom/secom_labels.data), [원본 설명](https://archive.ics.uci.edu/ml/machine-learning-databases/secom/secom.names)
- 실제 반도체 제조 공정의 1,567개 생산 개체에 관한 측정 특성·합불·검사 시각을 제공한다. 결측값이 있으며 장비 채널명·공학 단위·특정 팹의 신원은 공개 설명에서 확인하지 못했다.
- 공식 메타데이터는 591개 특성이라고 설명하지만, 이번에 원본 측정 파일 첫 행을 스트리밍해 확인한 필드 수는 590개다. 전체 도입 시 원본 구조를 다시 검증해야 한다.
- 합불 분석·측정 특성 분석에 적합하다. 한 장비 안에서 밸브·RF·로봇이 움직이는 시간별 로그는 아니다.
- UCI가 CC BY 4.0을 명시한다. 도입 시 저자·데이터셋 DOI·라이선스와 가공 내용을 함께 기록한다. DOI: `10.24432/C54305`.
- 접근 상태: 원본 측정·라벨 첫 행과 설명을 확인했다. 전체 ZIP은 다운로드하지 않았고 프로젝트에 원본 데이터는 포함하지 않았다.

## 현재 프로젝트에 적용할 개발 방향

특정 장비 모델이 정해지지 않았으므로 범용 장비 검토 구조를 먼저 만들고, 데이터마다 다음을 분리한다.

1. 공개 사양: 출처가 있는 장비 설명·명시된 사양만 표시한다.
2. 공개 실측: 실제 관측된 로그를 그대로 재생하되, 알 수 없는 단위·채널·레시피는 미상으로 남긴다.
3. 시뮬레이션 예제: 자체 모델로 생성한 값과 동작은 생성 데이터로 표시한다.
4. 현장 보정 프로파일: 향후 제공받을 장비별 단위·레시피·상태 전이·인터록·검증 데이터와 모델 버전을 묶는다.

첫 기능은 레시피 항목·단위 매핑, 설정값/관측값 시간축, 단계·이벤트 재생, 규칙 위반 설명이다. 자료가 없는 조건은 '검증 불가'로 표시한다. 과거 로그만 재생한 결과를 새 레시피의 사전 운전 검증이라고 부르지 않는다.

실제 장비 투입 전 판정에는 대상 장비의 사양·제어 순서·센서 응답과 독립 검증 데이터가 필요하다. 공개 연구 데이터만으로 삼성전자 또는 SK하이닉스의 특정 양산 장비에 대한 정확도·안전성을 입증할 수는 없다.
