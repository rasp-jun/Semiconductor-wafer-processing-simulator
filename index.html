MODEL CARD / PUBLIC REFERENCES

메모리 팹 통합 검토의 범위

전공정과 HBM 관련 후공정을 LOT 이력으로 연결한 독립 참조 모형입니다. SK하이닉스 내부 공정 순서·장비 목록·로그·생산 능력은 포함하지 않습니다. 실제 팹은 공정 목적·재료별 전용 장비와 수백 개 이상의 반복 단계를 사용합니다.

현재 실행하는 것

제품별 축약 경로, 공유 챔버 점유·대기, 조건 변화, 상류 구조 지표 전달, 합성 계측 규칙에 따른 보류, 동일 투입 계획의 변경 전후 비교.

모델의 경계

LOT 단위로 한 챔버를 점유합니다. 배치 처리·로봇·AMHS·정비 일정·실제 샘플링 검출 확률은 생략합니다. 시간은 모형 분이며 실제 사이클타임·생산 능력·전기 수율을 뜻하지 않습니다.

HBM 경로는 DRAM → TSV → 배선 → 박막화·적층의 연결을 설명하는 예제입니다. TSV 삽입 위치는 실제 통합 방식에 따라 달라집니다. 다이 분리 이후에도 부모 LOT ID를 유지하며, 개별 다이·스택 수량 분기는 아직 모델링하지 않습니다.

공개 기술 근거

  • SK하이닉스 · 식각과 고종횡비 구조 ↗DRAM 커패시터·NAND 채널홀의 공정 맥락
  • SK하이닉스 · TSV와 패키징 기술 ↗전공정 이후 패키지·테스트로 이어지는 제조 흐름
  • SK하이닉스 · MR-MUF와 HBM ↗적층·접합·봉지의 역할. 해당 장비·레시피 구현이 아님
  • Lam Research · HBM 공정 설명 ↗TSV 식각·금속 충진 공정의 역할. 특정 고객 납품 근거가 아님
