WHAT-IF REVIEW

변경 전후 비교

장비군 조건을 바꾸거나 챔버를 제외하면, 같은 투입 LOT의 전체 결과를 비교합니다.

실습 안내 · 검토 기록 목표 → 가설 → 비교 → 설명

교육 실습 · 챔버 편차 추적

  1. HAR 챔버 깊이 편차를 계산하고 첫 보류 시점으로 이동합니다.
  2. 보류 LOT의 식각·계측 이력에서 원인 공정과 발견 공정의 차이를 확인합니다.
  3. HAR-01을 제외하기 전에 완료 LOT과 대기 시간이 어떻게 바뀔지 가설을 적습니다.
  4. 제외 후 전체 비교에서 완료·보류·대기 변화를 관찰하고 가설을 설명합니다.

확인 질문: 계측은 편차를 만든 공정인가요? 챔버를 제외하면 왜 대기 시간이 늘어날 수 있나요?

실무 검토 연습 · 조건과 근거

  1. 투입 LOT·시나리오·보류 규칙을 확인하고 비교 기준을 계획 JSON으로 보관합니다.
  2. 한 번에 한 장비군 조건을 변경하고 동일 투입 계획의 결과를 비교합니다.
  3. 공정 이력 CSV와 리포트를 내려받아 변경 조건·영향 LOT·예외를 검토합니다.
  4. 실측 자료가 있다면 모델 근거 검증에서 보정 LOT과 후속 검증 LOT을 분리합니다.

규격 판정·양산 의사결정에는 별도의 실측 보정과 현장 검증이 필요합니다.

용어 LOT: 함께 추적하는 생산 묶음 · 챔버: 공정 처리 공간 · 레시피: 처리 조건 · 계측 GATE: 다음 단계 진행 여부를 확인하는 지점 · WIP: 투입 후 완료 전 LOT

기록은 현재 계획 JSON·리포트에 포함됩니다. 조건 변경 뒤에는 관찰 기록도 갱신하세요. 자동 채점이나 강사 승인 기록은 아닙니다.

MODEL CARD / PUBLIC REFERENCES

메모리 팹 통합 검토의 범위

전공정과 HBM 관련 후공정을 LOT 이력으로 연결한 독립 참조 모형입니다. SK하이닉스 내부 공정 순서·장비 목록·로그·생산 능력은 포함하지 않습니다. 실제 팹은 공정 목적·재료별 전용 장비와 수백 개 이상의 반복 단계를 사용합니다.

현재 실행하는 것

제품별 축약 경로, 공유 챔버 점유·대기, 조건 변화, 상류 구조 지표 전달, 합성 계측 규칙에 따른 보류, 동일 투입 계획의 변경 전후 비교.

모델의 경계

LOT 단위로 한 챔버를 점유합니다. 배치 처리·로봇·AMHS·정비 일정·실제 샘플링 검출 확률은 생략합니다. 시간은 모형 분이며 실제 사이클타임·생산 능력·전기 수율을 뜻하지 않습니다.

HBM 경로는 DRAM → TSV → 배선 → 박막화·적층의 연결을 설명하는 예제입니다. TSV 삽입 위치는 실제 통합 방식에 따라 달라집니다. 다이 분리 이후에도 부모 LOT ID를 유지하며, 개별 다이·스택 수량 분기는 아직 모델링하지 않습니다.

공개 기술 근거

  • SK하이닉스 · 식각과 고종횡비 구조 ↗DRAM 커패시터·NAND 채널홀의 공정 맥락
  • SK하이닉스 · TSV와 패키징 기술 ↗전공정 이후 패키지·테스트로 이어지는 제조 흐름
  • SK하이닉스 · MR-MUF와 HBM ↗적층·접합·봉지의 역할. 해당 장비·레시피 구현이 아님
  • Lam Research · HBM 공정 설명 ↗TSV 식각·금속 충진 공정의 역할. 특정 고객 납품 근거가 아님
