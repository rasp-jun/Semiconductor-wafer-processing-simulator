데이터 연동

운전 로그를 불러오고, 센서 태그를 모델 변수에 연결해 기준 조건과 비교합니다.
공개 실측으로 검증 ↗

범위파일은 이 화면의 메모리에서 처리하며 자동 업로드·자동 저장하지 않습니다. 데이터 출처는 제출자의 표시이며 실측 인증이 아닙니다. 현재 모델은 실측 보정 전입니다. 실제 장비의 명령·설정값을 변경하는 기능은 없습니다.

1. 운전 데이터 불러오기

최대 1.5 MB · 5,000시점 · CSV는 예제와 같은 헤더를 사용하세요. 장비별 원본 형식은 현장 수집기에서 공통 형식으로 변환합니다.

불러온 운전 데이터가 없습니다.

현장 서버에 수집된 운전 불러오기

이 페이지를 현장 STRATUM 서버에서 실행하고 검토 공간에 로그인한 뒤 사용하세요. 공개 사이트에는 수집 API가 없습니다.

2. 공정과 태그 연결

연속 센서 값은 이전 값을 유지하는 시간 가중 평균을 사용합니다. 도즈·사이클·표본 수는 종료 시각의 누적값을 사용합니다. 처리 시간은 로그의 처리 구간에서 계산합니다. 시간에 따른 비선형 반응을 직접 적분하는 모델은 아닙니다.

입력 웨이퍼 상태

입고 세정은 기준 실리콘에서 시작합니다. 이후 공정은 직전까지 완료한 이력이 필요합니다.

3. 입력과 계산 결과 확인

비교 기준도 동일한 입력 웨이퍼에서 계산합니다. 오염 지표·막 두께·단차는 모델 예측이며 실측 결과가 아닙니다. 전체 원본 로그, 사용하지 않은 채널, 앞 공정 이력, SHA-256 및 모델 버전은 결과 패키지에 포함됩니다. 해시는 파일 식별용이며 장비 인증 서명이 아닙니다.

현장 연결 범위

현재 지원: 파일 입력, 동일 서버의 인증된 수집 API, 태그 매핑, 단위 변환, 처리 구간 검증, 대표 조건 기반 계산과 기준 결과 비교.

SECS/GEM·EDA·OPC UA 직접 드라이버와 장비별 태그 정의는 현장 사양에 맞춘 별도 어댑터가 필요합니다. 단위나 입력 변수가 모델과 맞지 않으면 자동 추정하지 않고 계산을 중단합니다.

원천 시각과 품질 정보 설계 참고: OPC Foundation Data Access · 장비 통신 범위 참고: SEMI SECS/GEM
