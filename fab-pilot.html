FAB PILOT / OFFLINE SHADOW REVIEW

운전을 연결하고, 편차를 검토하다.

장비·챔버·레시피 개정을 고정하고, 로그 재계산과 계측 대조를 같은 조건으로 반복합니다.

파일은 브라우저 메모리에서 처리합니다. 현장 데이터·검토 메모를 자동 전송하거나 저장하지 않습니다. 이 도구의 범위는 파일럿 검토이며 실제 장비 명령이나 양산 투입 승인을 제공하지 않습니다.

1. 연동 프로파일과 운전 묶음

합성 예제는 마지막 운전에 오차를 넣어 경보를 확인합니다. 실측값이 없는 운전도 계산하지만 정확도 검증에서는 구분합니다. 공개 SPTS 파일은 단위 미확인으로 이 공통 형식에 자동 변환하지 않습니다.

프로파일 확인·편집

운전 묶음을 불러오세요. 파일당 최대 20 MB, 최대 100건입니다.

파일과 메모는 자동 저장되지 않습니다.

2. 계산과 검증 범위

    개별 계산 성공은 장비 인증이나 모델 유효성을 의미하지 않습니다. 실패한 행은 원인과 함께 남기며 제거해서 성적을 개선하지 않습니다.

    CSV는 필터된 요약표입니다. 원본·조치 기록 보존에는 전체 검토 패키지를 사용하세요.

    3. 실측 대조와 잔차 감시

    잔차 = 예측 − 계측. 기준과 검증은 LOT 및 기간을 분리합니다. 관리한계는 기준 잔차의 이동 범위로 추정하며 제품 규격과 다릅니다. 기준 안정성·측정 반복성·자기상관 확인 없이 이상 원인이나 공정능력(Cpk)을 단정하지 않습니다.

    두 운전의 조건과 결과 비교

    초록: 왼쪽 · 주황: 오른쪽. 각 운전의 처리 시작을 0초로 맞췄습니다. 시간축을 늘이거나 압축하지 않으며 값은 모델 단위로 변환합니다. 그래프는 처리 구간의 계단형 원본 추이입니다.

    운전별 상세 검토와 후속 조치

    조치 기록 완료는 이상 해소 검증이나 양산 승인이 아닙니다. 경보·원본 계산은 유지됩니다. 기록은 현재 입력 해시에 연결하며 패키지를 내려받아 보존합니다.

    4. 검토 메모와 재현 패키지

    메모는 전자서명이나 승인 기록이 아닙니다. 패키지를 내려받아야 보존됩니다. 가져온 패키지는 저장된 결과를 신뢰하지 않고 원본 입력으로 다시 계산합니다.

    현장 적용을 위해 준비할 항목

    장비 태그 사전과 레시피 개정 대조 → 원천 시각·품질·웨이퍼 이력 검증 → 계측기 반복성·재현성 확인 → 장비별 모델 보정 → 분리한 LOT·날짜의 오차 검증 → 명령 없이 병행 실행 → 담당 엔지니어의 운영 검토 순서로 진행합니다.

    실제 연결에는 현장 수집 어댑터, 네트워크·계정 권한, 데이터 보존과 복구 시험, 변경 승인 절차가 추가로 필요합니다. 이 화면은 그 절차를 자동 완료하거나 인증하지 않습니다.
