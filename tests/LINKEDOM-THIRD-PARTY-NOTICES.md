# Third-party notices for the bundled LinkeDOM test worker

Applies to `tests/linkedom.worker.mjs`. Verified on 2026-09-24.
Keep this file and `LINKEDOM-LICENSE` with source/test distributions that include
the worker. These notices do not apply a new license to WaferFlow's own code.

The worker matches the official npm `linkedom@0.18.12` `worker.js`, after CRLF
normalization. It was also rebuilt from the exact upstream release commit and
package lock; the rebuilt file matches byte-for-byte after the same normalization.
This identifies the bundled packages, including the two different entities
versions and the runtime helper generated by @rollup/plugin-commonjs. The
html-escaper dependency and native canvas are not present in the rendered bundle.

- Release commit: [dfc2fa88969b2d63014e3f6afd49a4e4449996e5](https://github.com/WebReflection/linkedom/tree/dfc2fa88969b2d63014e3f6afd49a4e4449996e5).
- Exact [package lock](https://github.com/WebReflection/linkedom/blob/dfc2fa88969b2d63014e3f6afd49a4e4449996e5/package-lock.json) and [Rollup config](https://github.com/WebReflection/linkedom/blob/dfc2fa88969b2d63014e3f6afd49a4e4449996e5/rollup/es.config.js).
- Machine-readable package versions, archive integrity, license hashes and rendered modules: [LINKEDOM-PROVENANCE.json](LINKEDOM-PROVENANCE.json).

License texts below were copied from the integrity-verified package archives,
except boolbase's omitted LICENSE, obtained from its original upstream
LICENSE-addition commit (whose index.js is identical to the npm version), and
XRegExp's LICENSE from the exact commit cited in the bundled source comment.
No copyright holder or copyright year was inferred.
