SPTS Omega i2L DSi Rapier의 공개 BOSCH 운전 로그와 웨이퍼 9점 실측값을 연결했습니다.

범위완료된 운전 로그로 결과를 추정하는 별도 통계 모델입니다. 센서 단위와 절대 시각 기준이 확인되지 않아 기존 CMOS 물리모델로 직접 변환하지 않습니다. 실시간 장비 연결·레시피 최적화·양산 판정에는 사용할 수 없습니다.

공개 데이터와 모델을 불러오는 중입니다…

학습하지 않은 날짜로 검증

MAE는 평균 절대 오차, RMSE는 큰 오차에 더 민감한 지표입니다. 비교 기준은 학습 데이터의 평균 깊이를 모든 웨이퍼에 동일하게 예측합니다. 한 날짜의 결과이며 다른 팹의 성능을 보장하지 않습니다.

운전 선택 후 브라우저에서 다시 계산

가로축: 첫 샘플부터 경과한 초. 세로축: 원본 수치이며 공학 단위는 미확인입니다. 그림은 원본 81시점으로 축약했으며 모델 특성은 전체 샘플로 계산했습니다. 장비의 품질 플래그는 제공되지 않았습니다.

실측 9점과 계산에 사용한 특성

출처와 재현 범위

Sayyed 외, BOSCH Plasma-Etching 데이터 · DOI 10.5281/zenodo.17122442 · CC BY 4.0

원본 NetCDF를 해독하고 날짜·웨이퍼 번호가 정확히 일치하는 9점 측정값만 연결했습니다. 9개 센서의 평균·표준편차·10/90 백분위로 ridge 회귀를 학습했습니다. 정규화는 학습 데이터만 사용했고, 정규화 계수 α=10은 검증 결과 확인 전에 고정했습니다. 입력 특성에 식각 깊이 측정값은 포함하지 않습니다.

원본 시간 메타데이터의 1970년 기준값과 실험 그룹의 2024년 날짜가 일치하지 않습니다. 상대 시간만 사용했습니다. 9점 평균은 전체 웨이퍼 지도가 아니며 원본 수동 측정에도 오차가 있습니다.
